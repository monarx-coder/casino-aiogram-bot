# casino-aiogram-bot
Бот в телеграмме построенный с помощью aiogram содержащий игры казино не являющимися реальными.

# Чат
В чате будет кнопка "Профиль" показывающая имя при регистрации, день регистрации и ниже то сколько вы уже зарегистрированы, также то сколько дней вы заходили в бота.

# Регистрация
Заходя в бота будет обязательна регистрация для аналитики. При регистрации необходимо будет указать вымышленное имя.

#Фон
Фон будет фиолетовым, слегка темного оттенка.
# Аналитика
Аналитика сыгранных игр будет подразделятся на:
• Процент побед - процент побед и поражений.
• Статистика за все время - статистика за все время пребывания в боте.
• Общая статистика - статистика игр за все время сыгранных в одном режиме.
• За сегодня - статистика игр за сегодняшний день 
• Последняя игра - последняя игра соответственно.
Примечание:
Статистика за последнюю игру будет аннулироваться при выходе из определенного режима в главное меню.

•По режимам - статистика игр для каждого режима.


Все вышеперечисленное(в заголовке Аналитика) будет находится ТОЛЬКО в меню бота.

## Тип аналитики
Процент побед - полоска заполненная цветами зеленый и красный, зелёный будет победой,крансый- проигрышем, на цвете будет написан процент того или иного результата.

Аналитика выигрышей и проигрышей т
е. За все время, общая статистика, ща сегодня и последняя будет строится на графиках типа
fill_between with transparency на сайте matplotlib..

Для анализа "По режимам" надо будет использовать горизонтальный график, являющийся такой же полосой как и в Проценте побед .
